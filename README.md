## Status

This repo holds the About (hub) page and the full AI Timeline. The four Object Record content timelines plus References (316 images, ~81MB total) are still hosted directly on Netlify and have not yet been pulled into version control here -- that's the next migration step, planned as part of moving hosting from Netlify to Cloudflare Pages.

## Why this repo exists

Netlify's free tier moved to a credit-based bandwidth model in September 2025, with a hard cap and no graceful overage. Cloudflare Pages is the planned replacement: no stated bandwidth cap on its free tier, and it deploys straight from a GitHub repo on every push -- no more manual drag-and-drop.
